## 🚀 О проекте

**GuepardVPN** — это коммерческий Telegram-бот для автоматизированной продажи VPN-подписок. Бот полностью автоматизирует цикл: регистрация пользователя → выбор тарифа → оплата → выдача ключа → уведомление об истечении → продление.

**Основные особенности:**
- Интеграция с VPN-панелью **RemnaWave** для автоматического создания/обновления пользователей
- 3 платёжные системы: карты (ЮKassa), Telegram Stars, криптовалюта (CryptoPay)
- Встроенный **Telegram Mini App** (веб-интерфейс внутри Telegram)
- Реферальная программа с автоматическим начислением бонусов
- Автопродление подписки
- Антиспам-мидлварь
- Полная административная панель

## 💳 Платёжные системы

### ЮKassa (карты РФ)
- Платёжный провайдер для карт Visa/MasterCard/МИР
- Webhook-обработчик на встроенном HTTP-сервере (aiohttp)
- Поддержка сохранённых методов оплаты для автопродления
- Настройки: `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`

### CryptoPay (криптовалюта)
- Интеграция через библиотеку `aiocryptopay`
- Поддержка USDT, BTC, ETH и других криптовалют
- Фоновая проверка статуса инвойсов с адаптивным backoff при таймаутах
- Настройки: `CRYPTOPAY_TOKEN`

### Telegram Stars ⭐
- Нативные платежи внутри Telegram без внешних шлюзов
- Обработка через `pre_checkout_query` и `successful_payment`
- Моментальное зачисление без ожидания подтверждений

Создайте файл `.env` в корне проекта:

```env

# Либо логин/пароль (если нет постоянного токена):

# === Ссылки на подписку ===
PROXY_URL_BASE=https://subs.ваш-домен.com
PROXY_PORT=8081
PROXY_HOST=0.0.0.0

# === Mini App ===
WEBAPP_URL=https://ваш-домен.com

# === CryptoPay ===
CRYPTOPAY_TOKEN=токен_от_CryptoPay_бота

# === ЮKassa ===
YOOKASSA_SHOP_ID=ваш_shop_id
YOOKASSA_SECRET_KEY=ваш_секретный_ключ
```

> Никогда не коммитьте `.env` в репозиторий! Файл уже добавлен в `.gitignore`.

## 🚀 Установка и запуск

### Локальный запуск (разработка)

Требования: Python 3.10+

```bash
# 1. Клонировать репозиторий
git clone https://github.com/BadiBay/GuepardVPN.git
cd GuepardVPN

# 2. Создать виртуальное окружение
python -m venv .venv

# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Создать и заполнить .env
# 5. Запустить бота
python bot.py
```

### Зависимости

| Пакет | Назначение |
|-------|-----------|
| `aiogram>=3.0.0` | Async фреймворк для Telegram Bot API |
| `aiohttp>=3.8.0` | HTTP-клиент/сервер (webhook, RemnaWave API) |
| `apscheduler>=3.10.0` | Планировщик задач (проверка подписок) |
| `python-dotenv>=1.0.0` | Загрузка `.env` файла |
| `aiocryptopay>=0.3.1` | Клиент для CryptoPay API |
| `yookassa` | SDK для ЮKassa |

## 🌐 API панель RemnaWave

Файл `remnawave_api.py` — асинхронный клиент для RemnaWave.

### Основные функции

| Функция | Описание |
|---------|---------|
| `get_token()` | Получение JWT токена (кэш 23 часа) |
| `add_client(telegram_id, expiry_ms)` | Создание нового VPN-пользователя |
| `update_client_expiry(uuid, user_id, expiry_ms)` | Обновление даты подписки |
| `get_subscription_url(telegram_id)` | Получение ссылки подписки |
| `reset_user_traffic(uuid)` | Сброс трафика и устройств |
| `disable_client(uuid)` | Деактивация пользователя |
| `enable_client(uuid)` | Активация пользователя |

### Аутентификация

Поддерживаются два режима:
1. **Постоянный токен** — `PANEL_TOKEN` в `.env` (рекомендуется)
2. **Логин/пароль** — `PANEL_USERNAME` + `PANEL_PASSWORD`, JWT кэшируется на 23 часа

## 📱 Telegram Mini App

Директория `webapp/` содержит клиентский веб-интерфейс, открывающийся внутри Telegram.

### Экраны Mini App

| Экран | ID | Описание |
|-------|-----|---------|
| Главное меню | `view-main` | Логотип, кнопки навигации |
| Тарифы | `view-tariffs` | Выбор периода и уровня подписки |
| Профиль | `view-profile` | Данные подписки, ключ, автопродление |
| Установка | `view-install` | Инструкции по настройке VPN |
| Бесплатный VPN | `view-free` | Реферальная ссылка, бонусы |

### URL-параметры

Бот передаёт данные в Mini App через URL:

```
https://guepardvpn.top/?tid=USER_ID&bal=BALANCE&end=SUB_END&uuid=SUB_LINK&ar=0&pm=0
```

| Параметр | Описание |
|----------|---------|
| `tid` | Telegram ID |
| `bal` | Баланс |
| `end` | Дата окончания подписки |
| `uuid` | Ссылка на подписку |
| `ar` | Автопродление (0/1) |
| `pm` | Сохранён ли метод оплаты (0/1) |

## 👮 Административная панель

Команда: `/admin` (только для пользователей из `ADMIN_IDS`)

**Возможности:**
- **Статистика** — всего пользователей, активных подписок
- **Выдать подписку** — Telegram ID + количество дней
- **Найти пользователя** — поиск по ID, отображение всех данных
- **Рассылка** — текст + опционально кнопка в формате `Название|https://ссылка`
- **Лимит устройств** — изменение `device_limit` для конкретного пользователя
- **Тест уведомлений** — принудительный запуск проверки истекающих подписок

## 🤝 Реферальная система

- Реферальная ссылка: `https://t.me/guepardvpn_bot?start=ref_TELEGRAM_ID`
- При регистрации нового пользователя по ссылке — `referrer_id` сохраняется в БД
- После первой оплаты нового пользователя — реферер получает **бонусные дни** подписки
- Информация доступна в разделе «Партнёрская программа»

## ⏰ Уведомления и планировщик

Используется `APScheduler` (AsyncIOScheduler). Фоновые задачи:

| Задача | Интервал | Описание |
|--------|----------|---------|
| `check_expiring_subscriptions` | ~15 мин | Уведомления за 24 ч до конца подписки |
| `check_expired_subscriptions` | ~15 мин | Деактивация истёкших подписок в RemnaWave |
| `check_cryptopay_invoices` | ~5 мин | Проверка крипто-инвойсов (адаптивный backoff) |
| `check_yookassa_payments` | ~5 мин | Проверка платежей ЮKassa |
| Автопродление | ~1 ч | Попытка автопродления для пользователей с сохранёнными картами |

## 🔒 Безопасность

- **Антиспам** — `ThrottlingMiddleware`: не более 1 запроса/сек на пользователя
- **Идемпотентность** — таблица `processed_payments` предотвращает двойное зачисление
- **Admin-only** — все административные хэндлеры проверяют `ADMIN_IDS`
- **Переменные окружения** — все секреты хранятся в `.env`, не в коде
